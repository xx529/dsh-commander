窗口怎么放：球窗保持 56 × 56；气泡是第二个透明窗，click-through，不抢焦点。贴屏幕右边时气泡在球左侧，贴左边自动翻到右侧；拖球或打开面板时收起，落点后再出现。

数据从哪来：Host 现在只发 turn/start、turn/end 与 assistant 文本，tool/进度被 M0 契约过滤。要出现「正在创建任务」，需要新增 activity 事件，从 tool/call + tool/result 映射；否则只能做 lite 版（正在思考 / 本轮完成）。

连接状态去哪了：球上不再放右下绿点。离线时球体整体去饱和并停动，面板头保留连接点与文字（实时同步 / 轮询同步 / 离线）。原来的点是重复信号，而且原生壳一直显示、没有 tooltip。

球体去旗标是纯 CSS；气泡不是。气泡要新增一个透明窗和 Host activity 事件，属于 Native 与 Host 契约变更，这次只做原型，没有改生产代码。

球窗固定 56 × 56、球体 inset 4 px，任何外扩光晕都会被窗口硬裁。四套材质都把光收在球内；气泡的阴影也收在 12 px 内边距里。球上不设右下状态点，连接状态交给球体降级材质和面板文字。
