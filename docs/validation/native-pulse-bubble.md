# 原生壳 B 球 + Lite 状态气泡（2026-11-26）

> 历史阶段文档：球体后来升级为 76×76 / 60px 液态金属，气泡/快捷输入统一为烟熏铬玻璃，working 改为银白卫星、完成改为绿色脉冲。最终实现与验证见 `docs/validation/native-shell-metal.md`；v0.5 起 working 气泡展示当前活动（`docs/validation/native-bubble-activity.md`）；本文保留 B/Lite 阶段结论。

## 结论

- 球体采用 B 方案「脉冲核心」：黑曜石球面 + 34px 冷核 + 两层声呐，居中无符号，右下无连接点。
- 连接状态改由球体降级材质（offline/reconnecting 灰化并暂停）与面板头连接点/文字表达；球上不再放点。
- 气泡只做 **Lite**：用现有 `commanderBusy` 显示「正在思考」；busy 结束显示「已完成 · 点击球查看」+ 绿色呼吸，约 5s 后文案收起，浮球转入未读绿色脉冲核心 + 双层声呐，直到用户点击浮球/打开面板确认；新回合 busy 时重置。不解析 tool/进度，不新增 Host 事件。
- 气泡是独立 336×76 透明窗，`set_ignore_cursor_events(true)`，不抢焦点；贴球左侧，空间不足自动翻到右侧；面板打开时隐藏，拖球时跟随。

## 交互（2026-11-26）

- 悬停高亮：Rust 80ms 轮询 `NSEvent.mouseLocation` + 球窗 frame，进入/离开发 `commander:ball-hover`；球页面加 `is-hover`。没有走窗口焦点，因此不需要先点一下球。
- 快捷输入：光标在球内停留 0.8s → 复用 bubble 窗切到输入；自动聚焦，Enter 发送，Esc 收起；空输入时光标离开球自动收起。消息走既有 `POST /commander/message`。收起后状态气泡恢复；光标离开球后才重新武装；面板打开时关闭。
- 真机探针：通过 bubble 页注入 `set_quick_input({open:true})` 验证窗口/焦点/UI，输入条正常出现。0.8s 悬停唤起依赖真实鼠标位置，未在探针里物理移动光标；重启后请用真实悬停验证。截图时 live 旧快捷输入还在同屏，有重影，因此不收录截图。
- 完成提示：快速输入发送 → busy 气泡「正在思考」；turn/end → 「已完成 · 点击球查看」绿色呼吸 5s；随后文案收起，浮球转未读绿色脉冲核心 + 双层声呐；点击浮球打开面板（`commander:mode` true）后 ack 清除；新回合 busy 重置。面板已打开时完成不弹提醒。连接短暂抖动不清掉已完成的未读状态。

## 已知限制

- 成功态「已完成 · 点击球查看」的真机截图未拿到（假 Host 的 status 帧与页面加载时序冲突）；阶段逻辑由 `bubblePhaseFor` 单测覆盖 busy→success，5s 定时与未读呼吸由 BubbleApp 的 `attentionTimer`/`setBallUnread` 控制；working 的卫星与未读的脉冲/声呐均由样式单测覆盖。
- 真机只验证了球在右半屏时的左侧气泡；左半屏翻转、拖球跟随、面板打开隐藏由 Rust 逻辑实现，未逐项真机截图。
- 页内 DSH 浮球（`Overlay.tsx` / `styles.ts`）本轮未改，仍是旧旗标/降级点；如需统一，另开一轮改 in-app 浮球。
- 需要重装 + 重启 native shell 才会加载新二进制与 `lib/window.js`；仅硬刷新不会更新原生壳。
- 悬停检测依赖主线程每 80ms 轮询，开销很小但会让壳的主线程每 80ms 醒一次；若后续觉得费电，可换成 NSTrackingArea。
- 完成未读态目前只存在页面内存：若 bubble 页重载，未读呼吸会丢；点击浮球/面板打开会清除。
